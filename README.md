# webbytega-site

Source for my personal portfolio and business site, live at
[webbytega.netlify.app](https://webbytega.netlify.app). Built in WordPress
and exported as a static site for fast, low-maintenance hosting on Netlify.

## What this demonstrates
- Managing a real, deployed site end-to-end: content, structure, and hosting
- Working with WordPress theming/content structure (about, projects, contact pages)
- Static-site deployment workflow (WordPress export → static hosting)

## Stack
WordPress (source), HTML/CSS/JS (exported static build), Netlify (hosting)

## Status
Live and actively used for freelance web design work.
